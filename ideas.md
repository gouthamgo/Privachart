<idea>
  **Design Movement**: Neo-Brutalism / Swiss Style Hybrid
  **Core Principles**:
  1. **Radical Transparency**: The design should reflect the privacy-first nature—clear, bold, and honest.
  2. **Data as Hero**: The charts themselves are the primary visual element; everything else supports them.
  3. **High Contrast**: Use strong contrast to guide the eye and create a sense of precision.
  4. **Functional Minimalism**: Every element must have a purpose; no decoration for decoration's sake.

  **Color Philosophy**:
  - **Intent**: Evoke trust, precision, and clarity. Avoid "friendly" pastels in favor of "professional" bold tones.
  - **Palette**: Stark Black (#1a1a1a) and White (#ffffff) base. Accent colors are vivid and data-centric: Electric Blue (#0055FF) for primary actions, Signal Orange (#FF4400) for alerts/highlights.

  **Layout Paradigm**:
  - **Asymmetric Grid**: Avoid the standard centered container. Use a split-screen approach where controls are on one side (sticky) and the visualization canvas takes up the rest.
  - **Modular Blocks**: Content is organized in distinct, bordered blocks that feel like physical cards or data sheets.

  **Signature Elements**:
  - **Thick Borders**: 2px-3px solid borders on all interactive elements.
  - **Monospace Headers**: Use a high-quality monospace font for headers to emphasize the "data" aspect.
  - **Raw Geometry**: Sharp corners, no rounded edges (0px border-radius).

  **Interaction Philosophy**:
  - **Tactile Feedback**: Buttons should feel "heavy" with distinct hover and active states (e.g., offset shadows that collapse on click).
  - **Instant Response**: Changes in data or settings should reflect immediately without transition lag, emphasizing the "local" speed.

  **Animation**:
  - **Snappy & Linear**: Animations should be fast (150ms) and linear. No bouncy springs.
  - **Glitch/Tech Effects**: Subtle "tech" transitions when switching chart types or loading data.

  **Typography System**:
  - **Headings**: 'JetBrains Mono' or 'Space Mono' (Monospace) - Bold, Uppercase.
  - **Body**: 'Inter' or 'Helvetica Now' - Clean, legible, high x-height.
</idea>

<idea>
  **Design Movement**: Glassmorphism / Ethereal Tech
  **Core Principles**:
  1. **Light & Air**: The interface should feel weightless, emphasizing the "cloud-free" (local) nature by being visually light.
  2. **Layered Depth**: Use translucency and blur to create hierarchy without heavy borders.
  3. **Fluidity**: Data is fluid; the interface should reflect this with soft curves and smooth transitions.
  4. **Immersive Canvas**: The chart area should feel like an infinite canvas, not a boxed container.

  **Color Philosophy**:
  - **Intent**: Create a calm, focused environment for analysis.
  - **Palette**: Soft, deep gradients. Background is a very dark, desaturated blue/slate (#0f172a). Accents are glowing gradients of Cyan (#06b6d4) to Violet (#8b5cf6).

  **Layout Paradigm**:
  - **Floating Islands**: Controls float above the canvas in semi-transparent panels.
  - **Central Focus**: The chart is always center-stage, with UI elements fading out when not in use.

  **Signature Elements**:
  - **Frosted Glass**: Backdrop-filter blur on all panels and modals.
  - **Soft Glows**: Subtle outer glows on active elements instead of hard borders.
  - **Super-Rounded Corners**: Large border-radius (24px+) for a friendly, organic feel.

  **Interaction Philosophy**:
  - **Hover-Reveal**: UI density increases only when the user interacts with specific areas.
  - **Smooth Flow**: Drag-and-drop interactions should feel magnetic and fluid.

  **Animation**:
  - **Slow & Smooth**: Longer duration (400ms+), ease-in-out curves.
  - **Morphing**: Charts should morph into each other (e.g., bar to line) rather than hard switching.

  **Typography System**:
  - **Headings**: 'Plus Jakarta Sans' - Geometric, friendly, rounded.
  - **Body**: 'DM Sans' - Clean, modern, approachable.
</idea>

<idea>
  **Design Movement**: Bauhaus / Constructivist Modern
  **Core Principles**:
  1. **Form Follows Function**: The interface is stripped down to its bare essentials, but styled with artistic intent.
  2. **Geometric Harmony**: Use of basic shapes (circles, squares, triangles) as UI elements.
  3. **Bold Typography**: Type is used as a graphical element, not just for reading.
  4. **Structured Chaos**: A grid that allows for dynamic, non-standard placement of elements.

  **Color Philosophy**:
  - **Intent**: Artistic, intellectual, and bold.
  - **Palette**: Off-white/Cream background (#fdfbf7). Primary colors: Bauhaus Red (#d03026), Blue (#2858a6), Yellow (#f2c326), and Black (#1a1a1a).

  **Layout Paradigm**:
  - **Mondrian Grid**: The layout is divided by strong black lines into rectangular sections of varying sizes.
  - **Sidebar Navigation**: A strong vertical sidebar that anchors the composition.

  **Signature Elements**:
  - **Geometric Icons**: Custom icons built from basic geometric shapes.
  - **Overlapping Elements**: Elements might slightly overlap or break the grid to create tension.
  - **Solid Shadows**: Hard, non-blurred drop shadows at 45-degree angles.

  **Interaction Philosophy**:
  - **Constructive**: Building a chart feels like assembling a physical object.
  - **Clicky**: Distinct, mechanical feel to interactions.

  **Animation**:
  - **Staggered**: Elements enter one by one, following the grid lines.
  - **Geometric Transforms**: Shapes rotate and scale rather than fade.

  **Typography System**:
  - **Headings**: 'Syne' or 'Clash Display' - Unique, artistic, bold.
  - **Body**: 'Public Sans' - Neutral, legible, balancing the display font.
</idea>
